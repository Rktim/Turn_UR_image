# Turn UR Image 🎨

**Turn UR Image** is a powerful and easy-to-use image transformation web app that allows users to upload an image and apply different artistic effects. Built with **Streamlit**, this app provides a seamless and interactive experience for enhancing images with just a few clicks.

🚀 **Live Demo:** [Turn UR Image](https://turnurimage.streamlit.app/)

---

## ✨ Features
- 📸 **Upload & Transform:** Upload any image in JPG, PNG, or JPEG format and apply artistic effects instantly.
- ✍️ **Sketch Effect:** Converts images into pencil-like sketches.
- ⚫ **Binary Effect:** Generates a high-contrast black-and-white version.
- 🎨 **Watercolor Effect:** Applies a smooth watercolor painting effect.
- ⏬ **Download Option:** Save and download transformed images with a single click.
- 🔥 **User-Friendly Interface:** Simple and intuitive UI built with **Streamlit** for easy access.
- 💡 **Real-Time Processing:** Instant application of effects with optimized performance.
- 🖼️ **Supports Multiple Image Formats:** Works with commonly used formats like JPG, PNG, and JPEG.
- 📊 **Lightweight & Fast:** Efficient processing with minimal resource consumption.

## 🛠 Installation & Setup

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/Rktim/Turn_UR_image.git
cd Turn_UR_image
```

### 2️⃣ Create a Virtual Environment (Recommended)
```bash
python -m venv venv  # Windows: python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
```

### 3️⃣ Install Dependencies
Ensure you have Python installed (>=3.8) and install the required dependencies:
```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Streamlit App
```bash
streamlit run app.py
```

This will launch the application in your browser where you can start transforming images.
